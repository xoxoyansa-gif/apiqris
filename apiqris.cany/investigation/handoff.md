# Handoff

Both apiqris.com and app.apiqris.com have been investigated, extracted, and integrated into this repository. The React SPA (app.apiqris.com) is installed in /app/ with entrypoints for /app/daftar/ and /app/masuk/. All CTA buttons across the landing pages have been updated from external app.apiqris.com links to internal /apiqris/app/daftar/ and /apiqris/app/masuk/ routes. Router basename and API endpoints are configurable.

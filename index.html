Apa itu API QRIS

API QRIS: QRIS yang bisa diajak bicara oleh sistem Anda

Jawaban singkatAPI QRIS adalah layanan yang membuat kode QRIS bernominal secara otomatis dan memberi tahu sistem Anda saat pembayaran masuk. Dengan APIQris, QRIS API itu memakai QRIS milik Anda sendiri, jadi dana tidak pernah lewat pihak ketiga.

QRIS statis yang biasa ditempel di kasir mengharuskan pembeli mengetik nominal dan penjual mengecek mutasi secara manual. Begitu penjualan pindah ke website atau WhatsApp, cara itu jadi lambat dan rawan salah.

APIQris menambahkan nominal ke QRIS Anda, memberi kode unik di setiap tagihan, lalu membaca notifikasi dana masuk dari aplikasi merchant di HP Anda. Hasilnya: pesanan berubah lunas sendiri, siang maupun malam.

import crypto from 'node:crypto';
import express from 'express';

const app = express();
app.post('/webhook/qris', express.raw({ type: 'application/json' }), (req, res) => {
  const sig = Object.fromEntries(req.get('X-APIQris-Signature').split(',').map((p) => p.split('=')));
  const expected = crypto.createHmac('sha256', process.env.APIQRIS_SECRET)
    .update(`${sig.t}.${req.body}`).digest('hex');
  if (!crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(sig.v1 ?? ''))) return res.sendStatus(401);

  const event = JSON.parse(req.body);
  if (event.event === 'invoice.paid') markPaid(event.order_id);
  res.sendStatus(200);
});
import hmac, hashlib, os
from flask import Flask, request, abort

app = Flask(__name__)

@app.post("/webhook/qris")
def webhook():
    sig = dict(p.split("=", 1) for p in request.headers["X-APIQris-Signature"].split(","))
    msg = f"{sig['t']}.".encode() + request.get_data()
    expected = hmac.new(os.environ["APIQRIS_SECRET"].encode(), msg, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(expected, sig.get("v1", "")):
        abort(401)
    event = request.get_json()
    if event["event"] == "invoice.paid":
        mark_paid(event["order_id"])
    return "", 200
Route::post('/webhook/qris', function (Request $request) {
    parse_str(str_replace(',', '&', $request->header('X-APIQris-Signature')), $sig);

    if ($request->input('event') === 'invoice.paid') {

    return response()->noContent();

func webhook(w http.ResponseWriter, r *http.Request) {
    body, _ := io.ReadAll(r.Body)
    sig := map[string]string{}
    for _, p := range strings.Split(r.Header.Get("X-APIQris-Signature"), ",") {
        if k, v, ok := strings.Cut(p, "="); ok {
            sig[k] = v
        }
    }
    mac := hmac.New(sha256.New, []byte(os.Getenv("APIQRIS_SECRET")))
    mac.Write([]byte(sig["t"] + "." + string(body)))
    if !hmac.Equal([]byte(hex.EncodeToString(mac.Sum(nil))), []byte(sig["v1"])) {
        http.Error(w, "invalid signature", http.StatusUnauthorized)
        return
    }
    w.WriteHeader(http.StatusOK)
}

FAQ

Pertanyaan seputar API QRIS

Apa itu API QRIS?

API QRIS adalah antarmuka pemrograman yang memungkinkan website, aplikasi, atau chatbot membuat QRIS bernominal secara otomatis dan menerima kabar ketika QRIS tersebut sudah dibayar.

Apa bedanya QRIS API APIQris dengan payment gateway?

Payment gateway menampung dana lalu mencairkannya dengan potongan biaya. APIQris memakai QRIS milik Anda sendiri sehingga dana langsung masuk ke rekening Anda, dan APIQris tidak memotong fee per transaksi.

Apakah API QRIS ini benar-benar gratis?

Ya, daftar gratis dan APIQris tidak memotong persentase transaksi. Potongan MDR dari bank atau e-wallet penerbit QRIS Anda (bila ada) tetap mengikuti ketentuan penyedia tersebut.

QRIS apa saja yang bisa dipakai?

QRIS merchant resmi dari bank atau e-wallet, seperti GoPay Merchant, ShopeePay, DANA Bisnis, BRI, BCA, Mandiri Livin’ Merchant, dan lainnya, selama aplikasinya menampilkan notifikasi dana masuk berisi nominal.

Bagaimana sistem tahu pembayaran sudah masuk?

Aplikasi pendamping APIQris di HP Android Anda membaca notifikasi dana masuk dari aplikasi merchant, lalu mengirim nominalnya ke server kami untuk dicocokkan dengan tagihan yang menunggu.

Apakah saya perlu memberikan password bank?

Tidak. APIQris tidak pernah meminta password internet banking, PIN, atau OTP Anda.

Apakah bisa untuk chatbot WhatsApp dan Telegram?

Bisa. Bot cukup memanggil API untuk membuat tagihan, mengirim gambar QR ke pengguna, lalu menerima webhook saat pembayaran lunas.

Bahasa pemrograman apa yang didukung?

Semua bahasa yang bisa melakukan HTTP request. Contoh kode tersedia untuk cURL, PHP, Laravel, Node.js, Python, dan Go.

Bagaimana jika dua pembeli membayar nominal yang sama?

Setiap tagihan diberi kode unik kecil sehingga totalnya berbeda, misalnya Rp50.123 dan Rp50.481, dan pembayaran bisa dicocokkan tepat.

Apakah aman?

Komunikasi memakai HTTPS, API key bisa dirotasi, dan setiap webhook ditandatangani HMAC SHA-256 agar server Anda bisa memastikan keasliannya.

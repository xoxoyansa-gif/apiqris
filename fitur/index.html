01 · Pembuatan QRIS

Pembuatan QRIS

Mengubah QRIS statis milik Anda menjadi QRIS bernominal untuk setiap transaksi.

QRIS dinamis

Nominal tertanam di QR (tag 54) dengan checksum CRC-16 baru. Data merchant tidak diubah.

Kode unik otomatis

Rentang bisa diatur, mode tambah atau kurang, dijamin unik selama tagihan menunggu.

Masa berlaku fleksibel

Atur per tagihan, misalnya 15 menit untuk checkout atau 24 jam untuk invoice.

Idempoten per order_id

Request ulang dengan order_id sama mengembalikan tagihan yang sama, tidak dobel.

Banyak QRIS

Hubungkan QRIS dari beberapa bank/e-wallet dan pilih per tagihan atau per toko.

Gambar QR siap pakai

Dapatkan string QRIS untuk dirender sendiri atau URL gambar PNG siap tampil.

02 · Deteksi pembayaran

Deteksi pembayaran

Mengetahui pembayaran masuk tanpa membuka aplikasi merchant dan tanpa menyimpan password bank.

Baca notifikasi dana masuk

Aplikasi pendamping Android membaca notifikasi aplikasi merchant secara real time.

Pencocokan otomatis

Dicocokkan berdasarkan total unik, QRIS, dan waktu notifikasi.

Dukungan dua HP

Pasang di dua HP sebagai cadangan, notifikasi ganda disaring otomatis.

Antrean offline

Saat sinyal hilang, notifikasi disimpan dan dikirim berurutan saat online.

Peringatan HP offline

Dapat kabar bila HP pendamping tidak aktif terlalu lama.

Pasangkan manual

Mutasi yang tidak cocok (salah nominal) bisa dipasangkan ke tagihan dalam satu klik.

03 · API & webhook

API & webhook

Antarmuka REST JSON yang sederhana dan webhook yang aman untuk developer.

REST API JSON

Buat, ambil, batalkan tagihan. Autentikasi Bearer, respons JSON ringkas.

Webhook HMAC SHA-256

Setiap callback ditandatangani dengan timestamp untuk mencegah pemalsuan dan replay.

Kirim ulang otomatis

Hingga 6 kali dengan jeda 1 mnt sampai 24 jam, plus tombol kirim ulang manual.

Mode uji (sandbox)

API key uji dan simulasi pembayaran untuk mengetes tanpa uang sungguhan.

Rotasi API key

Kunci bocor? Buat kunci baru dan cabut yang lama kapan saja.

cURL, PHP, Laravel, Node.js, Python, dan Go siap salin.

FAQ

Pertanyaan tentang fitur

Apakah semua fitur gratis?

Fitur inti (QRIS dinamis, deteksi, webhook, dashboard, link pembayaran) gratis dan tanpa potongan per transaksi dari APIQris.

Apakah bisa dipakai tanpa coding?

Bisa. Gunakan link pembayaran dari dashboard. Untuk otomatisasi ke sistem sendiri barulah perlu integrasi API atau plugin.

Apakah ada plugin siap pakai?

Pola integrasi WooCommerce dan WHMCS tersedia. Lihat panduan masing-masing di halaman integrasi.

Berapa banyak QRIS yang bisa dihubungkan?

Lebih dari satu. Cocok untuk usaha dengan beberapa cabang atau beberapa penyedia QRIS.

Apakah ada batas jumlah tagihan?

Ada batas wajar untuk mencegah penyalahgunaan, misalnya batas tagihan menunggu dan laju pembuatan per detik. Detailnya di dashboard.

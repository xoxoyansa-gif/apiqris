Pengantar

API QRIS APIQris adalah REST API berbasis JSON untuk membuat QRIS dinamis dari QRIS milik Anda sendiri dan mengetahui kapan pembayaran masuk. Dana pembeli langsung masuk ke akun merchant QRIS Anda, APIQris hanya mengurus data tagihan, pencocokan, dan webhook.

Base URLhttps://api.apiqris.com/v1
Formatapplication/json, UTF-8
AutentikasiBearer API key
Zona waktuISO 8601, Asia/Jakarta (+07:00)
Mata uangIDR, bilangan bulat rupiah
Versiv1

Mulai cepat

  1. Daftar dan upload QRISBuat akun, lalu unggah gambar QRIS merchant Anda.
  2. Pasang aplikasi pendampingPairing HP Android yang menerima notifikasi dana masuk dari aplikasi merchant.
  3. Ambil API keyMenu Developer: salin AQ_TEST_ untuk uji dan secret webhook.
  4. Buat tagihan pertamaPanggil POST /invoices dan tampilkan qr_image_url.
  5. Terima webhookVerifikasi tanda tangan, tandai pesanan lunas, balas 200.

Autentikasi

Setiap request wajib memakai HTTPS dan menyertakan API key di header Authorization. Request tanpa key yang valid akan ditolak dengan 401 UNAUTHORIZED.

Header request
Authorization: Bearer AQ_LIVE_xxxxxxxxxxxxxxxx
Content-Type: application/json
Accept: application/json
Jaga kerahasiaan API keyJangan menaruh key di kode frontend, aplikasi mobile, atau repositori publik. Bila bocor, rotasi key dari dashboard; key lama langsung tidak berlaku.

Mode uji & live

LiveAQ_LIVE_Produksi. Lunas hanya bila pembayaran nyata terdeteksi.

Status tagihan

pending

Menunggu pembayaran.

paid

Pembayaran terdeteksi dan cocok.

expired

Lewat masa berlaku tanpa pembayaran.

cancelled

Dibatalkan lewat API atau dashboard.

pending → paid  atau  pending → expired / cancelled. Status final tidak berubah lagi.

Kode unik

Notifikasi dana masuk hanya berisi nominal. Agar setiap pembayaran bisa dikenali, total tagihan ditambah kode unik kecil sehingga tidak ada dua tagihan pending di QRIS yang sama dengan total persis sama. Selalu tampilkan total_amount kepada pembeli, bukan amount.

ContohDua pesanan Rp50.000 pada waktu bersamaan menjadi Rp50.123 dan Rp50.481. Rentang dan mode kode unik (tambah/kurang) bisa diatur di dashboard.

Idempotensi

Pembuatan tagihan idempoten berdasarkan order_id. Jika koneksi terputus dan Anda mengulang request dengan order_id yang sama selama tagihan masih pending, APIQris mengembalikan tagihan yang sudah ada, bukan membuat yang baru. Aman untuk retry otomatis.

Verifikasi tanda tangan

Header X-APIQris-Signature berformat t=<timestamp>,v1=<hex>. Hitung ulang HMAC SHA-256 dari body mentah (sebelum di-parse) dan tolak bila tidak cocok atau timestamp lebih dari 5 menit.

Algoritma
signed_payload = timestamp + "." + raw_body
expected       = HEX( HMAC_SHA256(webhook_secret, signed_payload) )
valid          = constant_time_equal(expected, v1) AND |now - timestamp| <= 300
Webhook handler
<?php
$body = file_get_contents('php://input');
parse_str(str_replace(',', '&', $_SERVER['HTTP_X_APIQRIS_SIGNATURE'] ?? ''), $sig);
$expected = hash_hmac('sha256', $sig['t'] . '.' . $body, getenv('APIQRIS_SECRET'));

if (!hash_equals($expected, $sig['v1'] ?? '') || abs(time() - (int) $sig['t']) > 300) {
    http_response_code(401);
    exit;
}
$event = json_decode($body, true);
if ($event['event'] === 'invoice.paid') {
    tandai_lunas($event['order_id']); // fungsi milik aplikasi Anda
}
http_response_code(200);
Route::post('/webhook/qris', function (Request $request) {
    parse_str(str_replace(',', '&', $request->header('X-APIQris-Signature')), $sig);
    $expected = hash_hmac('sha256', $sig['t'].'.'.$request->getContent(), config('services.apiqris.secret'));
    abort_unless(hash_equals($expected, $sig['v1'] ?? ''), 401);

    if ($request->input('event') === 'invoice.paid') {
        Order::where('number', $request->input('order_id'))->update(['status' => 'paid']);
    }
    return response()->noContent();
});
import crypto from 'node:crypto';
import express from 'express';

const app = express();
app.post('/webhook/qris', express.raw({ type: 'application/json' }), (req, res) => {
  const sig = Object.fromEntries(req.get('X-APIQris-Signature').split(',').map((p) => p.split('=')));
  const expected = crypto.createHmac('sha256', process.env.APIQRIS_SECRET)
    .update(`${sig.t}.${req.body}`).digest('hex');
  if (!crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(sig.v1 ?? ''))) return res.sendStatus(401);

  const event = JSON.parse(req.body);
  if (event.event === 'invoice.paid') markPaid(event.order_id);
  res.sendStatus(200);
});
import hmac, hashlib, os
from flask import Flask, request, abort

app = Flask(__name__)

@app.post("/webhook/qris")
def webhook():
    sig = dict(p.split("=", 1) for p in request.headers["X-APIQris-Signature"].split(","))
    msg = f"{sig['t']}.".encode() + request.get_data()
    expected = hmac.new(os.environ["APIQRIS_SECRET"].encode(), msg, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(expected, sig.get("v1", "")):
        abort(401)
    event = request.get_json()
    if event["event"] == "invoice.paid":
        mark_paid(event["order_id"])
    return "", 200
func webhook(w http.ResponseWriter, r *http.Request) {
    body, _ := io.ReadAll(r.Body)
    sig := map[string]string{}
    for _, p := range strings.Split(r.Header.Get("X-APIQris-Signature"), ",") {
        if k, v, ok := strings.Cut(p, "="); ok {
            sig[k] = v
        }
    }
    mac := hmac.New(sha256.New, []byte(os.Getenv("APIQRIS_SECRET")))
    mac.Write([]byte(sig["t"] + "." + string(body)))
    if !hmac.Equal([]byte(hex.EncodeToString(mac.Sum(nil))), []byte(sig["v1"])) {
        http.Error(w, "invalid signature", http.StatusUnauthorized)
        return
    }
    w.WriteHeader(http.StatusOK)
}

Kirim ulang

Webhook dianggap berhasil bila server Anda membalas status 2xx dalam 10 detik. Bila gagal, APIQris mencoba lagi dengan jeda berikut:

#11 menit
#25 menit
#315 menit
#41 jam
#56 jam
#624 jam

Anda juga bisa melihat log respons dan menekan "kirim ulang" dari dashboard. Karena webhook bisa terkirim lebih dari sekali, pastikan proses Anda idempoten.

Kode error

Semua error memakai status HTTP yang sesuai dan body JSON berikut:

{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "amount minimal 1000"
  }
}

Checklist go-live

  • Ganti API key uji (AQ_TEST_) dengan key live (AQ_LIVE_)
  • Callback URL memakai HTTPS dan membalas 2xx dalam 10 detik
  • Tanda tangan webhook diverifikasi sebelum memproses pesanan
  • Proses webhook idempoten berdasarkan order_id
  • API key disimpan di server, tidak di frontend atau aplikasi mobile
  • HP pendamping online dan uji bayar Rp1.000 berhasil
